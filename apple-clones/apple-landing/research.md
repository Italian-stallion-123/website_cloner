## 4. LAYOUT SYSTEM

### Grid
- **System:** 12-column CSS Grid
- **Column gap:** 24px
- **Row gap:** 12px (between card rows)
- **Max-width container:** 980px (default), 692px (compact sections), 87.5% (small screens)

### Breakpoints
| Name | Width | Notes |
|------|-------|-------|
| xlarge | >= 1441px | Widest desktop |
| large | 1069px - 1440px | Standard desktop |
| medium | 735px - 1068px | Tablet |
| small | < 734px | Mobile |

### Section Layout Patterns
1. **Full-width heroes:** Edge-to-edge, ~580-680px tall, text centered over imagery
2. **Two-column product grid:** 2 cards side by side within max-width container, each card ~580px tall
3. **Horizontal carousel:** Full-width overflow-x scroll with snap-to behavior
4. **Multi-column footer:** 5 column groups collapsing to accordion on mobile

### Spacing
- **Between hero sections:** 12px margin
- **Between grid cards:** 12px gap
- **Section internal padding:** 64px-80px top/bottom
- **Card internal padding:** 40px-56px
- **Footer section padding:** 20px top/bottom
- **Nav horizontal padding:** 24px

## 6. INTERACTIONS & ANIMATIONS

### Navigation
- **Sticky:** Remains fixed at top on scroll
- **Backdrop blur:** `backdrop-filter: saturate(180%) blur(20px)` for frosted glass effect
- **Dropdown menus:** Slide down with opacity fade, ~300ms transition
- **Mobile:** Hamburger menu expands to full-screen overlay

### Scroll Animations
- **Hero sections:** Subtle parallax - background image scrolls slower than content
- **Product cards:** Fade-in-up animation triggered when scrolling into viewport
- **Entertainment carousel:** Horizontal scroll with CSS scroll-snap
- **Implementation:** GSAP ScrollTrigger for scroll-synced animations

### Hover Effects
- **Nav links:** Opacity change on hover (1.0 -> 0.7), ~200ms transition
- **CTA links ("Learn more"):** Color shifts to slightly lighter blue, subtle underline appears
- **CTA buttons (filled):** Background darkens slightly (#0071e3 -> #0077ed)
- **Product cards:** Subtle scale transform (1.0 -> 1.01) with box-shadow increase
- **Footer links:** Opacity change, text underline on hover

### Button/CTA Styles
#### Link-style CTA ("Learn more", "Buy"):
```css
color: #06c;
font-size: 21px;
font-weight: 400;
text-decoration: none;
/* Hover: underline, color slightly shifts */
/* Right arrow indicator: > character or SVG chevron after text */
```

#### Filled Button CTA (when used on product pages):
```css
background-color: #0071e3;
color: #fff;
border-radius: 980px; /* Fully rounded pill */
padding: 8px 22px;
font-size: 17px;
font-weight: 400;
border: none;
cursor: pointer;
transition: background-color 0.3s;
/* Hover: background-color: #0077ed */
```

#### Outline Button (secondary):
```css
background-color: transparent;
color: #06c;
border: 2px solid #06c;
border-radius: 980px;
padding: 8px 22px;
font-size: 17px;
```

### Transitions
- **Default transition:** `all 0.3s ease` on interactive elements
- **Nav dropdown:** `opacity 0.3s, transform 0.3s`
- **Focus states:** `outline: 2px solid #0071e3; outline-offset: 0px;`

## 9. RESPONSIVE BEHAVIOR

### Desktop (>1068px)
- Full navigation text visible
- Hero images at maximum resolution
- Product grid: 2 columns
- Entertainment: ~4 visible carousel items
- Footer: 5 column groups side by side

### Tablet (735px - 1068px)
- Navigation may condense (smaller text)
- Hero images swap to medium resolution
- Product grid: 2 columns (narrower)
- Reduced padding throughout
- Footer: 3 columns or accordion

### Mobile (<734px)
- Hamburger navigation menu
- Hero images swap to small/portrait versions
- Product grid: 1 column (stacked)
- Entertainment carousel: 1-2 visible items
- Footer: Full accordion, expandable sections
- Typography scales down per the type scale table

## 10. KEY DESIGN PRINCIPLES OBSERVED

1. **Minimalism:** Vast white space, limited text, product-focused
2. **Visual hierarchy:** Hero > Featured > Grid > Content cascade
3. **Monochromatic base:** Black, white, gray palette lets product colors shine
4. **Consistency:** Every card follows the same pattern: Headline + Subtitle + Dual CTAs
5. **Full-bleed imagery:** Heroes extend edge-to-edge for immersive feel
6. **Centered typography:** Nearly all text is center-aligned
7. **Paired CTAs:** "Learn more" (informational) + "Buy/Shop" (transactional)
8. **Progressive disclosure:** Top-level overview -> click for details
9. **Performance:** Lazy-loaded images, responsive srcset, optimized assets
10. **Accessibility:** Focus states, semantic HTML, ARIA labels, high contrast ratios

## 11. ASSETS & RESOURCES FOR RECREATION

### Image CDN Patterns
- Product images: `https://www.apple.com/v/home/{version}/images/{section}/...`
- Entertainment media: `https://is1-ssl.mzstatic.com/image/thumb/...`
- Logos: `https://www.apple.com/v/home/{version}/images/tv-gallery/logo_hero_light__*.png`

### Font Recommendation for Clone
- **Primary:** Inter (closest publicly available alternative to SF Pro)
- **System fallback:** `-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, "Helvetica Neue", Arial, sans-serif`
- **Alternative:** Use system font stack which will use SF Pro on macOS/iOS automatically

### Icon Requirements
- Apple logo SVG
- Search magnifying glass icon
- Shopping bag icon
- Right chevron/arrow for CTA links (">")
- Hamburger menu icon for mobile

### Animation Library
- GSAP + ScrollTrigger for scroll-based reveals and parallax
- CSS `scroll-snap-type: x mandatory` for entertainment carousel
- CSS `backdrop-filter: saturate(180%) blur(20px)` for nav glass effect

### Placeholder Strategy for Images
- Use CSS gradients (linear-gradient with Apple-esque colors: deep purple, blue, teal)
- Or use Unsplash product photography
- Dark gradient for iPhone hero: `linear-gradient(180deg, #1a1a2e 0%, #0a0a0a 100%)`
- Light gradient for MacBook: `linear-gradient(180deg, #f5f5f7 0%, #e8e8ed 100%)`
